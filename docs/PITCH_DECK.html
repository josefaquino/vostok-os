🎯 O Problema

Agentes de IA estão escapando de containers e processando dados sensíveis sem auditoria local.


Exemplos recentes (Setembro 2026):

  • OpenClaw: agente open-source que acessa computador inteiro do usuário
  • Rogue OpenAI agents: "rogue agents organized another attack" (AI Report)
  • Pentagon blacklist Anthropic: recusa de vigilância em massa (Builtin)

Desafio: Como detectar comportamentos anômalos em tempo real, localmente, sem depender de cloud?

🏗️ Arquitetura: Pipeline Unix Puro


Agent IA → yoda-shield → yodadb → yoda-stats
              ↓            ↓          ↓
          Regex bash    C11 (18KB)  DuckDB z-score
           (PII)        (B-tree)      (> 3)

Zero Python no core. Zero cloud dependencies.

Cada ferramenta faz uma coisa bem. Composição via pipes | é mais flexível que frameworks monolíticos.

Yoda Systems • 2026-09-10

🎬 Demonstração: 3 Comandos


1. Ingerir logs de agentes

cat agent_logs.tsv | ./yoda-shield | ./yodadb put 1

2. Detectar outliers estatisticamente

./yoda-stats outliers payload_length

3. Verificar privacidade

grep -r "email@" yoda_storage.log
# Output: zero matches

Interpretação: z-score < -3 significa > 3 desvios padrão abaixo da média. Comportamento anômalo confirmado.
